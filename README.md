# Proyecto SSDD

Proyecto desarrollado para la asignatura de **Sistemas Distribuidos** de la Universidad de Murcia durante el curso 2025-2026.

Este repositorio reúne el trabajo realizado en equipo para diseñar, implementar y coordinar una solución técnica basada en varias tecnologías de desarrollo, con enfoque en organización del código, integración de componentes y buenas prácticas de colaboración.

## Qué aporta este proyecto

- Trabajo en equipo sobre una base de código real.
- Uso de varias tecnologías en un mismo entorno de desarrollo.
- Organización de un proyecto con componentes de backend y frontend.
- Experiencia práctica en herramientas habituales de desarrollo y despliegue.

## Tecnologías utilizadas

- **Java**
- **Python**
- **HTML**
- **CSS**
- **JavaScript**
- **Docker**
- **Makefile**
